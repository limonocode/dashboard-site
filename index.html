FAQ

Is it really free?

Yes. The dashboard, groups, search, cleanup, export, and optional cloud sync are free. There are no in-app purchases in this version.

Where is my data stored?

On your device, in the browser. Optional cloud sync (email + library snapshot) and an optional webhook send data off the device only after you tick a consent box in Settings. See the privacy policy.

Do I need an account?

No. The core product works without an account. An account is only for optional cloud sync.
