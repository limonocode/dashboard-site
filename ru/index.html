Поиск

Мгновенный поиск по всему, операторы tag:/type:, умные группы, палитра команд.

Ресёрфейсинг

«Забытая сохранёнка» на каждой новой вкладке, «ровно год назад», снуз и кнопка-рандом.

Порядок

Дубли, битые ссылки, разбор-режим, массовые действия, правила авто-тегов.

Сессии и пространства

Окно в группу одним кликом, проект открывается одной кнопкой.

Свой вид

Светлая и тёмная темы, мудборд с превью, свои фоны, цвета групп.

Без замка

Экспорт в JSON и Markdown в любой момент.
